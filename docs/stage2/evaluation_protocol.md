# Frozen unseen-participant evaluation protocol
RECOMMENDATION: follow configs/stage2_protocol.json and reports/stage2/split_manifest.json exactly. This is a versioned local checkpoint, not external preregistration.

Population/training: eligible T2D participants only; no healthy/prediabetes pooling in this experiment. Outer leave-one-participant-out holds out each eligible person once. Outer training has the other 13. Inner three-fold validation assigns sorted outer-training participant IDs round-robin (validation groups 5/4/4; training groups 8/9/9). All observations/sensors from a held-out person remain outside training. Only Dexcom is admitted. No random window split, full-trace normalization or outer-test tuning.

Exact participant membership and participant-origin-set counts/hashes are stored for every outer/inner partition. The deterministic local origin_membership.csv supplies the underlying IDs without copying features into the review ZIP. Both feature variants use the identical membership, target values and paired evaluation origins.

For each later learned family and feature variant, choose hyperparameters solely by equally weighted inner-validation participant MAE. The candidate grid and order are frozen: four Ridge alphas and four compact histogram-boosted configurations. Exact ties choose the first configured candidate. Fit scalers only on inner training, then refit only outer training after selection. No imputation, clipping or whole-trace transform. Use the same four-candidate budget for both variants within each family.

Required later methods: persistence g(t); 15-minute trailing OLS extrapolation g(t)+30*slope([t-15,t]); Ridge with training-only standard scaling; one compact histogram-gradient-boosted family with max_iter=100 and early_stopping=false. Inputs and targets are mg/dL; slope is mg/dL/min. All predictions are unbounded; report implausible/out-of-range predictions rather than silently clipping. Insufficient history is an exclusion shared by every method. No predictions have been computed on real held-out participants in Stage 2; baseline formulas are tested only on synthetic fixtures.

Primary reporting metric: mean of per-participant MAEs, equal person weight. Secondary: mean per-participant RMSE, window-weighted MAE/RMSE, persistence/trend-relative improvement, and per-person values/counts. Fusion deltas must be paired within the same learned family and origin set. Report both families; do not choose an overall fusion-success narrative using outer-test results. Report worsening, null gains, uncertainty and participants harmed. No claim of benefit follows from freezing this design.

Use participant bootstrap (2000 fixed-seed draws) on paired per-person deltas for later exploratory intervals; never independently resample overlapping windows. Fourteen people limit precision and population generalization. For fitting, Stage 3 must document estimator/software versions and use the same deterministic training-row order and default uniform-origin weighting for both variants; a weighting change requires a new explicit protocol checkpoint before any test inspection.

Outer test results cannot guide a new feature, candidate, threshold, sensor, split or preprocessing choice. A design changed after seeing them is a new exploratory experiment requiring a new untouched evaluation source for confirmatory claims. Cross-validation does not remove upstream two-sided interpolation or certify live-equivalent availability. Clinical efficacy, treatment optimization, India-population validity and calibrated alert probabilities remain unestablished.
