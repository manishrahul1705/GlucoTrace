# Stage 2 data contract
RECOMMENDATION: the machine-readable contract is configs/stage2_protocol.json and immutable dataclass field definitions are in src/glucotwin/contracts.py. This is retrospective released-signal research. Every origin carries causal_certification=false. No native-reading heuristic or new value interpolation is used.

ParticipantBaseline: participant_id; cohort_group; age, bmi, hba1c, fasting_glucose; explicit units; source_file; 1-based source_row excluding header; provenance SHA256 reference; baseline_availability_status; actual_available_at=null; baseline_valid; exclusion_reason. The exact mapping is Age -> age (years), BMI -> bmi (kg/m^2), A1c PDL (Lab) -> hba1c (operational percent), Fasting GLU - PDL (Lab) -> fasting_glucose (mg/dL). No similarly named fingerstick is substituted. Keys must be unique numeric integers; unmatched/duplicated participant keys fail the join.

VERIFIED SOURCE: the original dataset paper's Methods gives HbA1c group thresholds in percent. The source dictionary says mmol/mol. INFERENCE: operational percent is appropriate for the released 4.6–8.5 values and published grouping; raw values are not numerically converted. This unit-source conflict remains documented, not silently erased. Baseline-before-evaluation is an ASSUMPTION because result-report times are absent. No medication history, longitudinal EHR or independently verified clinical diagnosis is fabricated. T2D cohort categorization uses HbA1c >6.4%, so HbA1c participates in both selection and one candidate feature set.

ReleasedGlucoseObservation: participant_id; sensor=Dexcom GL; event_time (shifted naive datetime); glucose_mg_dl; valid; source_file/source_row; provenance_reference; processing_status=released_potentially_interpolated; actual_available_at unknown; availability_verified=false; native_observation_status=unknown. Absent timestamp cells have row_present=false and source_row missing, separate from present rows with invalid glucose. No observed/derived flag is invented.

ForecastOrigin: deterministic origin_id; participant_id; issue_time; history_start=t-60; target_time=t+30; source/provenance reference; eligibility/exclusion reasons; task label; causal_certification=false. The ID hashes protocol version, participant, sensor, issue time, history and horizon; it is the same on the one/five-minute grids. Primary sampling is index position modulo five from the first parsed timestamp. This is a computational choice, not a native sensor anchor.

RECOMMENDATION: reject timestamp parsing failures, duplicate timestamps, non-monotonic inputs and off-minute-grid records rather than silently sorting/aggregating. Actual inputs pass these checks. Establish a minute index without filling values. A valid glucose cell is numeric, finite and within inclusive 40–400 mg/dL, following Stage 1. Require every cell in inclusive [t-60,t] and an exact valid t+30 cell. A nearest target is never substituted. Future cells between t and t+30 need not all be present for regression; event labels use their own stricter support rules.

Input-access modes are distinct: retrospective access slices by event_time <= issue_time and advertises upstream limitations. Causal access additionally requires verified nonmissing actual_available_at <= issue_time for all consumed records; it rejects this actual release. Successful retrospective replay cannot certify causal access. Dataset-level two-sided interpolation can carry later-anchor information even when our own feature builder is purely trailing.

Local files under data/processed/stage2 contain baseline/observation/origin/feature/label contracts. They remain ignored and excluded from the review ZIP. Source hashes, participant-level aggregates and origin-set hashes are review artifacts, not unrestricted redistribution permission.
